# Obsidian Vault Template

一个可以直接手写、也可以交给本地 Agent 协助维护的轻量 Obsidian 模板。HOME 管待办，项目页存上下文，Daily 按需做日终回顾。

## 开始使用

1. 在 GitHub 使用 **Use this template** 创建自己的仓库，或通过 **Code → Download ZIP** 下载并解压；也可以克隆本仓库。
2. 在 Obsidian 中选择 **打开本地仓库 / Open folder as vault**，选择包含 `HOME.md` 的目录。
3. 在 **设置 → 第三方插件 / Community plugins** 中安装并启用 **Tasks**。保持 Tasks 的全局过滤器为空，让普通 checkbox 能被汇总。
4. 打开 [HOME](HOME.md)，在阅读视图或实时阅览中查看任务；没有安装并启用 Tasks 时，查询区块不会变成待办清单。
5. 推荐使用 **Journals** 管理日记、周记和日历导航，核心 **Templates** 按需用于普通笔记。采用 Journals 后，关闭核心 **Daily notes**，无需再安装 **Periodic Notes** 和 **Calendar**。完整步骤见 [插件清单与设置](<90 System/插件清单与设置.md>)。

本仓库不包含 `.obsidian` 目录、插件程序或本机配置，也不会自动安装插件或运行 Agent。首次打开后由 Obsidian 在本地生成配置，Git 会忽略整个 `.obsidian/` 目录。个人笔记本换机时，可通过 Obsidian Sync 或复制自己的配置目录沿用设置；仅在未迁移配置时重新设置。

HOME 当前需要 **Tasks 7.23.0 或更新版本**。推荐组合为 **Tasks + Journals**；不使用周期笔记插件时，也可手动或由 Agent 创建日记、周记。插件清单、配置步骤、换机同步及排障说明统一维护在 [插件清单与设置](<90 System/插件清单与设置.md>)。

## 先体验，再写自己的内容

文件名以「演示-」开头的四篇笔记都是虚构案例，涵盖多项目、多模块、等待实验、截止日期和日终回顾。案例日期固定为 2026-09-20 至 2026-09-25；晚于这些日期打开时，带旧日期的未完成任务会出现在「需要重排」。可以通过任务编辑按钮改成当前日期，体验区域变化。

开始正式使用时，将这些演示笔记移出仓库，并移除使用说明里不再需要的演示入口；再在 `40 Projects` 中添加自己的项目。不要把个人记录回传到这个模板仓库。

模板仓库后续更新不会自动覆盖你已创建的个人仓库。需要更新时，比较并选取框架改动即可。

## 框架

从 [工作台](HOME.md) 开始。只记下一次能接着做所需的内容。

| 位置 | 用途 |
|---|---|
| [HOME](HOME.md) | 看待办、选今天做什么、安排日期和勾选完成 |
| 40 Projects | 保存项目与模块的任务、进展、结果和下一步 |
| 10 Journal / Daily | 可选的日终回顾，记录变化原因、感受和工作方式上的观察 |

## 平时怎么用

- **开始**：在 HOME 看「今天」和「需要重排」；需要规划时展开「其他待办」，选几项设置计划日期。
- **新增**：项目任务写在对应模块下；独立小事写 [零散待办](10%20Journal/Action%20List.md)；归属不明先写 [随手记](00%20Inbox/Capture.md)。
- **推进**：在 HOME 勾选或编辑任务；需要留下结果或判断时，进入原项目追加一两句。
- **收工**：更新项目进展。想保留当天的反思时再写 Daily，不要求每天写。

任务用 `- [ ] 具体动作` 即可，日期可选。计划日期表示想哪天做，截止日期表示最迟哪天完成。新项目放入 Projects 后会自动纳入查询；一个项目默认一篇笔记，多条工作线按模块分区。

Daily 不负责规划，也不保存另一份待办。你可以手写，也可以让 Agent 根据你提供的事实更新相关笔记。

## 和 Agent 一起用

让能够读写这个文件夹的 Agent 先读 [AGENTS](AGENTS.md)，然后自然地说：

- 「我今天有两个小时，帮我选一下先做什么。」
- 「给这个项目的开发模块加一项：核对接口，明天做。」
- 「今天先到这里，帮我记下进展。」
- 「我想回顾一下今天为什么一直被打断。」

Tasks 负责在 Obsidian 内汇总任务；Agent 在对话中按需读写文件。打开仓库不会自动运行 Agent 或自动生成每日总结。

## 其他目录按需使用

- 20 Raw：原文、附件或来源引用。
- [Wiki](30%20Wiki/index.md)：以后还会复用的理解。
- 40 Projects / Routines：重复工作的方法，不是待办实例。
- 50 Outputs：需要交付或分享的成果。
- 10 Journal / Weekly：可选的周复盘，不要求先写满 Daily。
- 90 System：Agent 约定的配套说明、可选模板和变更记录。

按插件设置说明配置后，日记保存到 `10 Journal/Daily`，周复盘保存到 `10 Journal/Weekly`，正文模板位于 `90 System/Templates`；需要时再创建笔记，模板不必填满。

操作细节和案例入口见 [90 System/工作台使用说明](90%20System/%E5%B7%A5%E4%BD%9C%E5%8F%B0%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E.md)。

# 工作台使用说明

每天打开 [[HOME|工作台]]。任务只保留在原笔记中，在工作台勾选或编辑会更新原文。

## 三个区域

- **今天**：计划今天做，或今天截止的任务。
- **需要重排**：过去安排但未完成，或已过截止日期的任务；已进入「今天」的任务不再重复显示在这里。
- **其他待办**：未来安排和没有日期的任务，默认折叠，点击展开。按项目文件分组，规划时从中挑选。

每条未完成任务只显示在一个区域。真实截止日期仍保留在任务上，即使已重新安排到今天也不会被抹去。

## 查看和操作

- 点复选框：完成任务，原项目也会同步变为完成。
- 点任务旁的编辑按钮：修改内容、计划日期或截止日期。
- 点任务旁的来源链接：进入项目的具体模块，查看背景或补充进展。
- 没有匹配任务时，该区域保持空白。

计划日期（⏳）表示打算哪天做；截止日期（📅）表示最迟哪天完成。只有真实期限才填写截止日期，没有日期也可以先保留任务。

## 新任务写在哪里

- 项目任务：写在 `40 Projects` 中对应项目的模块标题下。
- 独立的一次性事项：写在 [[10 Journal/Action List|零散待办]]。
- 暂时不知道归属：写在 [[00 Inbox/Capture|随手记]]。

HOME 是汇总与编辑已有任务的入口；新增时点击上面的入口，或请 Agent 写入对应位置。用普通 Markdown checkbox（`- [ ] 具体动作`）即可。新项目会自动进入查询，不必在 HOME 再登记一次。普通段落不进入清单。Daily、Weekly、Wiki、Outputs、模板和 Routines 中的 checkbox 也不在当前汇总范围。

## 项目和 Daily

**规划在 HOME，事实在 Project，日终回顾按需写 Daily。**

Daily 可以记录当天变化的原因、感受和跨项目观察，不重复保存 checkbox 或项目正文。仅有项目进展时，更新项目即可；不用另外总结一遍。

你可以手写，也可以收工时让 Agent 帮你整理。Agent 按实际日期写入 `10 Journal/Daily/YYYY-MM-DD.md`；按 [[90 System/插件清单与设置]] 配置所选日记入口后，插件使用相同目录和 Daily 模板，但只创建或打开笔记，不会自动总结一天。

不要求每天写，不自动补记。回顾中出现新行动时，将任务放回项目、零散待办或收件箱。需要整理资料时打开 [[30 Wiki/index]]。

## 演示案例

文件名以「演示-」开头的内容均为虚构，用于体验汇总和任务编辑。日期会随时间进入不同区域；在界面中修改的演示任务会保留你的操作结果。

- [[40 Projects/演示-上线实验|上线实验]]：一个项目内并行推进开发、结构探索和解码策略；等待原因写在记录中，检查结果作为未来任务。
- [[40 Projects/演示-论文修改|论文修改]]：第二个项目，展示截止日期与计划日期的区别。
- [[00 Inbox/演示-临时事项|临时事项]]：尚无项目归属的待办，以及不进入清单的普通想法。
- [[10 Journal/Daily/演示-2026-09-21|日终回顾]]：记录跨项目的观察，不再做日计划。

体验时可在 HOME 修改一项任务的计划日期、勾选完成，再通过来源链接查看原文。任务数量和所在区域随日期及操作变化，不以固定演示数字为准。

演示结束后，可以将这几个「演示-」文件移出仓库；不要复制备份到 Projects 或 Inbox，否则会再次进入清单。

## 可选字段与配置

- 开始日期和优先级可暂不填写。当前 HOME 不按开始日期隐藏任务，也不按优先级排序。
- Tasks 保持全局过滤器为空，以汇总普通 checkbox；HOME 自己限定目录。若以后设置了全局标签过滤器，未带该标签的任务不会被收录。
- 推荐组合为 Tasks + Journals，核心 Templates 按需用于普通笔记；采用 Journals 后关闭核心 Daily notes，无需 Periodic Notes 和 Calendar。插件版本、日记／周记设置及不使用 Journals 时的替代方式，统一见 [[90 System/插件清单与设置]]。
- 模板不包含 `.obsidian` 配置或插件程序。首次使用时按设置说明配置；个人笔记本换机可同步或复制自己的配置，无需一律重配。Git 忽略默认 `.obsidian/` 目录；主题、同步和账号设置保持用户自己的选择。

日记和模板设置的官方说明：[Journals](https://srg-kostyrko.github.io/obsidian-journal/)、[Templates](https://obsidian.md/help/plugins/templates)。
